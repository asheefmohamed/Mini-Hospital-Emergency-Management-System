# Mini Hospital Emergency Management System

A Java-based system built for the CIT300 Data Structures and Algorithms assignment.

## Data Structures Used
1. **Binary Search Tree (BST)**: Used for storing patient records using `Patient ID` as key (In-order traversal, Search, Delete, Insert).
2. **Queue (FIFO)**: Used for managing arriving emergency room patients.
3. **Stack (LIFO)**: Used to maintain completed treatment history.
4. **Singly Linked List**: Linked to each patient record to manage their previous visit details.

## How to Run
1. Compile: `javac *.java`
2. Run: `java Main`
